DSD 转 PCM

DSD 文件

    支持批量选择或拖入 DSF / DFF 文件。

    输出设置

    自动策略：DSD64 → 88.2 kHz；DSD128 / 256 / 512 → 176.4 kHz。较少见的 48 kHz 家族相应输出 96 / 192 kHz。这是默认输出策略，不代表 DSD 与 PCM 的音质等价。

    高级设置

    FLAC 输出使用 24-bit 整数；32-bit 浮点仅适用于 WAV。

    默认 0 dB，不自动增加 6 dB 或逐曲归一化。转换前检查处理后的峰值；24-bit 输出超出满幅时会提示降低增益。

    输出采样率升至 352.8 / 384 kHz 时仍使用约 30 kHz 的低通，适用于后续处理，不会增加保留的高频范围。

    保留源声道布局。输出文件自动避开同名文件，原始 DSF / DFF 保留。
